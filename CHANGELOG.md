# Changelog

All notable changes to LockPeek are documented here.

## [0.1.0] - 2026-09-04

- Add read-only file and directory holder inspection.
- Add Windows Restart Manager and POSIX `lsof` adapters.
- Add human-readable and JSON output with script-friendly exit codes.
- Add explicit no-kill safety boundary, tests, CI, security policy, and release record.
